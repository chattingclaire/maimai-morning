# Maimai 的早晨

一个猫咪模拟器的网页版：在洒满晨光的卧室里当一只叫 Maimai 的猫。实时渲染（three.js），打开就能玩：https://chattingclaire.github.io/maimai-morning/

这里只有打包好的游戏文件。需要独立显卡；笔记本上如果很卡，在 Windows「设置 → 系统 → 屏幕 → 显示卡」里把浏览器设成「高性能」，再重开浏览器。

署名：房间来自 Room at Dawn（Leon Lin，MIT）。音乐 Kevin MacLeod《Meditation Impromptu 02》（incompetech.com，CC BY 4.0）。环境声 Silas S. Brown《Dawnchorus-uk》（公有领域）和 Gravity Sound《Rustling leaves》（CC BY 4.0）。Maimai 模型的蒙皮权重拟合时用了 AI4Animation 的动捕数据（CC BY-NC 4.0），仅供非商业用途。three.js、cannon-es、three-mesh-bvh：MIT。
